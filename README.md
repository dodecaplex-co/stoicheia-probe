# stoicheia-probe

A throwaway repository for probing GitHub's merge queue, organisation-required
workflows and artifact attestations for dodecaplex-co/stoicheia's factory
(discovery item d-probes-0). Nothing here is part of the edition.

`payload.txt` is the probe's subject. The workflow that dodecaplex-co/stoicheia-signer
holds, required here by an organisation ruleset, signs its bytes. Pull requests change
only `payload.txt`.
